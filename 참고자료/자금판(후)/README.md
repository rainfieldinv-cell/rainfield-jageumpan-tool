# 자금판 자동화 - 사채권자 자금판

레인필드투자자문 · 부동산 금융 SPC "사채권자 자금판" 엑셀 자동 생성 웹 앱

## 실행 방법 (설치 필요 없음)

`index.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다.
(인터넷 연결 없이도 동작하도록 라이브러리를 `vendor/` 폴더에 함께 넣어 두었습니다.)

## 만드는 자금판 종류 (상단 탭으로 전환)

- **(1) 사채권자 자금판** — 완성
- **(2) 업무수탁사용 자금판** — 완성 (기초자산 Cash-in + 사모사채 Cash-out 좌우결합)

## 핵심 원칙

다운로드된 엑셀의 이자지급 스케줄 표에는 **값이 아니라 실제 수식**이 들어갑니다.
예: `=EDATE(C15,3)`, `=ROUNDDOWN($D$5*I15*F15/365,0)`, `=D5` (상단 발행금액 참조).
→ 엑셀에서 셀을 직접 고치면 다른 셀도 자동으로 다시 계산됩니다.

## 진행 상태 (사채권자 자금판 완성)

- [x] 1단계 — 프로젝트 뼈대 / 폴더 구조 / 화면 레이아웃
- [x] 2단계 — 발행 기본조건 입력 폼(+계좌 블록)
- [x] 3단계 — 이자지급 스케줄 자동 계산(편집 가능)
- [x] 4단계 — 2회차 자동채움 / 필드 단위 독립수정
- [x] 5단계 — 엑셀 다운로드(예시 파일과 동일 구조 + 실제 수식)

## 업무수탁사용 자금판 (완성)

- 상단 탭에서 전환. 기초자산(Cash-in) + 사모사채(Cash-out)를 지급날짜 축 기준으로 하나의 표에 좌우결합.
- 이자지급 주기 규칙(선취/후취 + "N개월 × M회 / 만기까지" 여러 줄), 방식 A 분할, 윤년미적용(365) 계산.
- 1회 = 사모사채 1개, 2회 = 1-1/1-2회 + 추가자산관리수수료.
- 엑셀: "이자 스케줄" 탭 1개 파일, 실제 수식(일수 =말일-초일, 이자 =ROUNDDOWN(원금*금리*일수/365,0), 합계 =SUM).

## 윤년 열 제거 (2026-08-24)

**윤년미적용 · 윤년적용** 열은 화면·엑셀 양쪽에서 삭제했습니다.
값이 이자계산일수와 똑같이 찍혀 구분이 안 되고, 이자금액도 어차피 365 기준으로만 계산했기 때문입니다.

- 사채권자: 12열 → 10열 (`구분 초일 말일 지급일 일수 금리 인출 이자 인수수수료 비고`)
  - 엑셀 열이 2칸씩 당겨져서, 샘플에서 뽑은 서식을 `STYLE_SRC` 로 새 열에 되짚어 입힙니다.
  - 비고를 `K:M` 로 병합해 표 오른쪽 끝을 상단 계좌 블록(…M)과 맞췄습니다.
- 업무수탁: 세그먼트당 9열 → 7열. 열 배치가 `B / C~I / J~P / Q~W / X` 로 바뀌었고,
  상단 정보블록 값 열도 같이 이동(기초 `D`, 사모 1-1 `L`, 1-2 `S`).

## 원천세 표 (2026-08-24)

두 자금판 모두 스케줄 표 아래에 원천세 표가 붙습니다 (`js/wht.js`, 공용).

- 컬럼: `이자지급일 | 이자금액(세전) | 원천세 | 지방세 | 합계`
- **원천세 = 금액 × 원천세율**, **지방세 = 원천세 × 지방세율**, 둘 다 **10원 단위 절사**
- 세율은 화면에서 직접 입력(기본 14% / 10%) — 딜마다 다를 수 있으므로 하드코딩하지 않습니다.
- 체크박스를 끄면 화면·엑셀 양쪽에서 표가 빠집니다.
- 업무수탁은 예시와 동일하게 **기초자산(Cash-in) 참여수수료 + 이자**가 대상입니다.
- 엑셀에도 값이 아니라 수식: `=ROUNDDOWN(C24*14%,-1)`, `=ROUNDDOWN(D24*10%,-1)`, `=E24+D24`

## 검증 (수식엔진 formulas)

- 사채권자: `F15=90` / `I15=69,041,095` / `I16=70,575,342` / 합계 `I19=279,999,998`
- 업무수탁 1회: 기초 `I14=98,630,136`·합 `I19=399,999,997` / 사모 `P15=69,041,095`·합 `P19=279,999,998`
- 업무수탁 2회: 추가자산관리수수료 `X15=12,328,768` (= 기초이자 − Σ사모이자, 검산 일치)
- 원천세: 70,575,342 → 9,880,540 / 988,050 / 10,868,590 — **샘플 `자금판.xlsx` 실제값과 일치**
- 셀 클릭 시 값이 아니라 수식이 보이고, 원금·금리·날짜를 바꾸면 자동 재계산.
