# 자금판(후) 원본 — 보관용

지금 쓰는 자금판 자동화(이 저장소)의 **계산 규칙과 엑셀 서식이 여기서 왔습니다.**

## 뭐였나
계약서를 읽지 않고 값을 손으로 넣어 **이자지급 스케줄**을 만들던
순수 HTML/JS 도구입니다. 브라우저에서 ExcelJS 로 엑셀을 직접 만들었습니다.
자금판(전)과 합치면서 이 도구는 문을 닫았고, 그 내용이 이 저장소의
5·6단계(이자스케줄 만들기 · 엑셀 다운로드)가 되었습니다.

## 왜 남겨 두나
숫자나 서식이 이상할 때 **무엇이 맞는지 대볼 기준**이 필요해서입니다.

  SPEC_이자스케줄.md   ★ 계산 규칙·엑셀 서식 명세 (537줄). 가장 중요합니다.
  js/schedule.js      경계 모델 (구간 i 초일=경계[i], 말일=경계[i+1])
  js/wht.js           후순위대여 원천세·지방세 (10원 단위 절사)
  js/holidays.js      영업일 조정 (말일 이동 / 말일 고정 / 조정 안 함)
  js/excel.js         사채권자 자금판 서식
  js/excel_uw.js      전체(업무수탁) 자금판 서식
  index.html · css    화면 구성
  검증샘플_*.xlsx      이 도구가 만들던 결과물 — 대조용

## 옮길 때 확인한 것

  엑셀   이자 스케줄 시트 281칸, 사채권자 160칸, 전체 317칸이

## 주의
  · 안내문 예시의 계좌번호는 실제 번호가 아니라 0 으로 바꾼 예시입니다.
  · vendor(ExcelJS) 와 샘플 엑셀은 크기가 커서 안 가져왔습니다.
    ExcelJS 는 다시 받으면 되고, 샘플은 실제 고객 파일이라 올리지 않습니다.
